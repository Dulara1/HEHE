# 💗 A Little Question For You

A romantic interactive proposal website made with **HTML + CSS + JavaScript**.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will give you a public link.

### Personalize it

Open `index.html` and change the text inside the sections.

The "YES" screen and the running "maybe later" button are controlled by `script.js`.

> Tip: If you want music, add an audio file to the repo and connect it to a real `<audio>` element. Browsers generally block autoplay until the visitor interacts with the page.
